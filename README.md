# CATKRL

Code and data accompanying the manuscript

> **Aligning Neural Population Patterns Facilitates Motor Learning Transfer**
> Xiang Zhang, Zhiwei Song, Xiang Shen, Shuhang Chen, Yifan Huang, José C. Príncipe, and Yiwen Wang

Clustering Alignment-based Transfer on Kernel Reinforcement Learning (CATKRL) is a neural decoding framework that models motor learning transfer by aligning action-specific neural clusters across tasks in a low-dimensional feature space. Corresponding clusters are matched with a linear alignment estimated by iterative closest point. The framework was evaluated on chronic electrophysiological recordings from rats trained sequentially on a one-lever pressing task and a two-lever auditory-discrimination task.
